# Security

This repository is a benchmark. It does not ship production credentials.

Report a vulnerability in the benchmark code, or a secret that was committed here, to security@truefoundry.com. You can also use GitHub private vulnerability reporting on this repository. Please include the file path and enough detail to reproduce the finding. Do not open a public issue for an unfixed secret or credential.

We will acknowledge a report within three business days. The redacted trajectory release is generated data. If you find a private identifier that the redaction missed, treat that as a security report too.
